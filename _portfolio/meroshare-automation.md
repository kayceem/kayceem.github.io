## Overview
Meroshare Automation is a Python-based tool designed to streamline operations related to IPO (Initial Public Offering) processes, report generation, and EDIS (Electronic Depository Information System) management in Nepal's stock market.

## Key Features
- Automated IPO application processing
- IPO result retrieval
- EDIS operations management
- Headless browser support for automation
- User management utilities

## Technologies
- **Database**: Database utilities for user management
- **Browser Automation**: Headless browser support

## Functionality
- Run IPO applications with optional headless mode
- Retrieve and process IPO results
- Manage EDIS operations for individual users
- Database-backed user management
