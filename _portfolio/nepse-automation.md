## Overview
NEPSE Automation is a Python-based automation framework designed to interact with various Nepal Stock Exchange platforms. The project streamlines interactions with multiple stock market platforms through automated processes.

## Key Features
- **Multi-platform Support**: Integrates with Meroshare, NepseAlpha, and NEPSE TMS
- **Captcha Handling**: Automated captcha processing system
- **Data Processing**: Comprehensive data collection and processing
- **Platform Automation**: Automated interactions with stock exchange platforms

## Technologies
- **Language**: Python (100%)
- **Platforms**: Meroshare, NepseAlpha, NEPSE TMS
- **Automation**: Web scraping and automation tools
- **Captcha**: Automated captcha handling

## Components
- `meroshare.py`: Meroshare platform automation
- `nepsealpha.py`: NepseAlpha integration
- `nepsetms.py`: NEPSE TMS automation
- Captcha handling module
- Data processing scripts

## Use Cases
- Automated stock trading operations
- Market data collection
- Portfolio management automation
- Trading platform integration
